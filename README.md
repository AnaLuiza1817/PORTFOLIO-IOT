# Sobre as atividades

Durante as aulas de IoT, foram desenvolvidos diferentes circuitos utilizando o Arduino Uno e componentes eletrônicos. As atividades tiveram como objetivo compreender na prática o funcionamento de entradas, saídas, sensores e atuadores, além de desenvolver a lógica de programação aplicada à eletrônica.


## Aula 04 — Botão e LEDs

Nesta atividade foi desenvolvido um circuito utilizando botão, dois LEDs e resistores O objetivo foi utilizar o botão como entrada para controlar os LEDs.

### Funcionamento

A cada clique no botão, o circuito muda de estado:

* Primeiro clique → liga o LED verde.
* Segundo clique → mantém o LED verde ligado e liga o LED azul.
* Terceiro clique → desliga os LEDs.
* O ciclo pode ser repetido novamente.

## Aula 04 — Micro Servo Motor e Potenciômetro

Nesta atividade foi utilizado um potenciômetro para controlar um micro servo motor .O Arduino realiza a leitura da posição do potenciômetro e utiliza esse valor para determinar o ângulo do servo. O servo pode se movimentar em uma faixa de aproximadamente 0° a 180°, acompanhando a variação do potenciômetro.

### Componentes

* Arduino Uno
* Potenciômetro
* Micro servo motor
* Protoboard
* Jumpers

## Aula 05 — Sensor PIR e LED

Nesta atividade foi utilizado um sensor PIR, responsável por detectar movimento. Quando o sensor identifica uma movimentação, o Arduino recebe o sinal e aciona o LED.


### Componentes

* Arduino Uno
* Sensor PIR
* LED
* Resistor
* Protoboard
* Jumpers


## Aula 05 — Desafio

No desafio da aula foi desenvolvido um circuito utilizando botão, LEDs e resistores. A proposta foi aplicar os conhecimentos adquiridos durante as atividades anteriores para criar uma sequência de acionamento dos LEDs através do botão.

### Componentes

* Arduino Uno
* LEDs
* Botão
* Resistores
* Protoboard
* Jumpers
